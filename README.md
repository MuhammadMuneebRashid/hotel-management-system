#  Hotel Management System

A **console-based Hotel Management System** developed in **Python** using **Object-Oriented Programming (OOP)** concepts. This project allows users to manage hotel rooms by adding rooms, viewing available rooms, booking rooms, and canceling reservations through a simple menu-driven interface.

##  Features

* Add new hotel rooms
* View available rooms
* Book a room
* Cancel room bookings
* Track room availability
* Easy-to-use menu-driven interface

##  Technologies Used

* Python 3
* Object-Oriented Programming (OOP)

##  Project Structure

```text
Hotel-Management-System/
│── hotel_management.py
│── README.md
```

##  Getting Started

### Prerequisites

* Python 3.x installed on your computer

### Run the Project

1. Clone the repository:

```bash
git clone https://github.com/your-username/Hotel-Management-System.git
```

2. Navigate to the project folder:

```bash
cd Hotel-Management-System
```

3. Run the program:

```bash
python hotel_management.py
```
